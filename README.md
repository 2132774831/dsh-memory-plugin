# dsh-local-memory

**DSH 的纯本地长期记忆** —— 跨对话、跨项目，数据只存在你本机的一个 JSON 文件里。

不联网、不调用任何大模型、不需要 API key、不用 Docker、不用起服务。装完就能用。

---

## 它解决什么问题

AI 每次开新对话都从零开始：不记得你的偏好，不记得上个会话定下的约定，也不记得上次踩过的坑。

这个插件给 DSH 配一个**记忆本**：

- 对话里确认了值得长期保留的结论 → 写进记忆本；
- 下次新对话，相关记忆会自动出现在上下文里（或模型主动检索）；
- 你可以在设置页里**直接翻看、新增、编辑、删除**这些记忆。

---

## 为什么是「纯本地」

市面上更"聪明"的记忆方案（比如 Hindsight）通常是**一个独立服务 + 一个大模型**：
它用大模型"理解"你的话、抽取要点，再把记忆存进数据库。

代价是：你得跑一个服务、配一把 API key，而且"理解"这一步要把内容发到大模型厂商的云上。

这个插件走了另一条路：**不做语义理解，只做关键词匹配**。

| | 纯本地（本插件） | 服务型方案（如 Hindsight） |
|---|---|---|
| 单独跑服务 | 不用 | 要 |
| 大模型 key | 不用 | 要 |
| 联网 | 不用 | 要（抽取那一步） |
| 数据在哪 | 你本机一个 JSON 文件 | 服务端数据库 |
| 检索方式 | 关键词匹配（中文按二字组合） | 语义检索、图谱推理 |
| 装完即用 | 是 | 否 |

**够用吗？** 对"记住偏好 / 约定 / 决策 / 坑"这类需求，够用。中文按二字组合切词
（「鉴权设计」→ 鉴权 / 权设 / 设计），比单字精确得多，又不需要分词器。

## 记忆存在哪

```
~/.dsh/dsh-local-memory.json
```

一个纯文本 JSON，可以直接用编辑器打开、改、备份、同步：

```json
{
  "version": 1,
  "memories": [
    {
      "id": "m-abc123-xy",
      "text": "鉴权用的是轮询而不是 webhook，因为要避免公网回调",
      "tags": ["topic:auth"],
      "project": "acme-payments-api",
      "createdAt": 1767225600000,
      "updatedAt": 1767225600000,
      "hits": 3
    }
  ]
}
```

插件配置在 `~/.dsh/dsh-local-memory-config.json`。

## 四个工具

| 工具 | 干什么 |
|---|---|
| `memory_save` | 记住一条结论（文本重复时**不新增**，只合并标签并刷新时间） |
| `memory_search` | 按关键词检索（默认搜全部记忆，不论哪个对话、哪个项目写的） |
| `memory_list` | 列出最近的记忆 |
| `memory_forget` | 删除一条记忆（按 id） |

---

## 自动回忆

每次模型回答前，插件拿你这一轮的输入去记忆本里做一次关键词检索，命中的条目会作为
**一条附加上下文**注入。纯本地、微秒级，没有超时问题。

它不会硬塞无关记忆：查询为空、太短（默认 < 8 字）、或完全没命中时，就什么都不注入。

---

## 设置页

设置 → **本地记忆**，分三块：

**记忆（查看 / 新增 / 编辑 / 删除）**
- 关键词筛选框
- 「+ 新增记忆」表单
- 每条记忆显示正文、标签、项目、时间、被用过几次、id
- 每条都能**编辑**、**删除**（删除有二次确认）

**存储**
- 记忆文件路径、配置文件路径
- 条数 / 标签数 / 项目数 / 文件大小
- 已用过的标签与项目一览

**设置**
- 启用本地记忆（总开关）
- 每轮自动回忆 + 最多注入几条 + 输入短于此不触发
- 写入时自动打项目标签
- 把记忆库说明写进系统提示词
- 记忆条数上限
- 存储文件路径

设置保存**即时生效**，不用重启。

---

## 项目标签是怎么来的

写入记忆时，插件按会话工作目录认一下项目名，作为标签存下来（方便按项目筛选，
**不影响**默认检索范围——默认始终搜全部记忆）：

- 逐级向上找有可读 `config` 的 `.git`（worktree 的 `.git` 文件指针也认；
  空 `.git` 目录不算）；
- 家目录是硬边界，绝不越过；
- 有 remote 就用 `owner/repo`（跨 clone 稳定），否则用目录名。

## 配置项

`~/.dsh/dsh-local-memory-config.json`

| 字段 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 总开关 |
| `storeFile` | `~/.dsh/dsh-local-memory.json` | 记忆文件路径 |
| `maxMemories` | `5000` | 条数上限，超出丢最旧的（10–100000） |
| `autoRecall` | `true` | 每轮自动回忆 |
| `autoRecallMaxItems` | `5` | 最多注入几条（1–20） |
| `autoRecallMinChars` | `8` | 输入短于此不触发（0–500） |
| `autoTagProject` | `true` | 写入时自动打项目标签 |
| `injectBrief` | `true` | 是否把记忆库说明写进系统提示词 |

## 安装

见 [INSTALL.md](./INSTALL.md)。最短路径：

```bash
dsh plugin --profile desktop add <本目录绝对路径>
```

装完重启 dsh web，设置页会出现「本地记忆」。

## 卸载

```bash
dsh plugin --profile desktop remove dsh-local-memory
```

**记忆文件不会被删** —— 想清掉就自己删 `~/.dsh/dsh-local-memory.json`。
